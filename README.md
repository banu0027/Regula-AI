# Regula AI – Landing Page
Static site (HTML/CSS/JS, no build step). Open `index.html` in a browser, or deploy the folder to any static host.

- `index.html` – all sections, SEO title/meta
- `css/styles.css` – design tokens in `:root`
- `js/main.js` – mobile menu, active-nav highlighting, form validation

Notes: the demo form validates client-side only; connect it to a backend/form service (e.g. Formspree) in `main.js` before launch. Email is a placeholder. Regula AI is presented as a proposed concept; no stats, customers, or approvals are claimed. Fonts (Sora, Inter) load from Google Fonts with system fallbacks.
